# 项目任务

在本项目中，你需要与组员组队（**每组最多4名学生**），复现一篇围绕**可学习性/学习理论**展开研究的学术论文。项目目标是深入理解论文的核心方法、理论贡献，若论文包含实证验证工作，也需一并理解复现。

## 核心要求

### 论文选题

所选论文必须聚焦可学习性三大基础方向中的**至少一项**：

1. **估计误差（样本复杂度）**
2. **逼近误差（表达能力）**
3. **优化误差（计算复杂度）**

**禁止选择**：仅对神经网络做零散定制改进、缺乏理论支撑的应用型论文（例如推荐系统、计算机视觉、自然语言处理等领域纯应用层面的模型微调类论文）。

### 复现任务

1. 研读并解析论文，掌握其核心理论贡献；
2. 若论文包含实证实验，需使用原数据集或其他合适的公开数据集完成实验复现；
3. 若部分极其晦涩的技术细节难以完全理解也可接受，只需尽力把握理论结论的核心内涵与意义即可。

## 提交成果要求

需提交单个压缩包文件，内含以下所有内容：

### 书面报告

需涵盖以下五点内容：
(1) 论文所要解决的研究问题；
(2) 该研究问题面临的核心难点与挑战；
(3) 论文解决方案综述（理论贡献及算法贡献）；
(4) 用于验证理论的实验设计与结果分析（如有）；
(5) （可选）对论文方法的潜在改进思路与拓展研究方向思考。

### 演示幻灯片

精简版PPT，对书面报告内容进行概括梳理。

### 演示视频

录制**时长不超过15分钟**的PPT讲解视频，将视频上传至网盘（谷歌云盘、Dropbox等），并在提交材料中附上视频链接。

### 代码文件（如有）

复现实证实验所使用的完整代码。

## 论文选题参考指引

可选取机器学习与学习理论**顶会、顶刊**的近年论文，例如：ICML，NeurIPS，ICLRL，COLT，JMLR
